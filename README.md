A resignation letter exactly one line long, and funny, entered in make.fun's "The One-Line Exit" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
